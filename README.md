# ArtSpace Art Gallery

A beautiful art gallery website showcasing famous artists and their masterpieces - built with only HTML & CSS

## About

This website features:
- Artist profiles (Da Vinci, Monet, Picasso, Van Gogh)
- Gallery of famous paintings
- Information about each artwork
- Ticket booking page
- Shop page for art merchandise

## Technologies Used

**Only HTML and CSS** - No JavaScript, frameworks, or libraries were used in this project.

## Pages

- `index.html` - Home page
- `about.html` - About the gallery
- `artists.html` - List of featured artists
- `artist-da-vinci.html` - Leonardo da Vinci profile
- `artist-monet.html` - Claude Monet profile
- `artist-picasso.html` - Pablo Picasso profile
- `artist-van-gogh.html` - Vincent van Gogh profile
- `paintings.html` - Gallery of paintings
- `tickets.html` - Ticket booking
- `shop.html` - Art merchandise shop

## Styling

All styling is done in `style.css` using modern CSS techniques including:
- CSS Grid and Flexbox for layouts
- Custom properties (CSS variables)
- Responsive design
- Smooth animations and transitions
